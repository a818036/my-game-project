# 神洲三國：開發規格與第一階段原型

規則基準：規則手冊 **v3.15**、軒轅天生技全錄 **v1.10**。兩份原始手冊保留於 `docs/source/`，來源及 SHA-256 記錄於 `SOURCE_MANIFEST.json`。規格包依兩份最新版原檔整理，沒有以舊版替代。

## 遊戲定位與規格

單人、繁體中文的三國人生與世界模擬遊戲。完整目標涵蓋出生、家庭與成長，可走平民、商人、遊俠、仕宦、軍政等路線。第一階段只交付可驗證的小型地方生活原型，不代表完整三國模擬。

規格文件：

1. [遊戲需求](docs/GAME_REQUIREMENTS.md)
2. [技術規格](docs/TECHNICAL_SPEC.md)
3. [開發路線](docs/ROADMAP.md)
4. [驗收案例](docs/ACCEPTANCE.md)
5. [Codex 指令](docs/CODEX_PROMPTS.md)
6. [規則手冊 v3.15](docs/source/神洲三國_規則手冊_v3.15.md)／[天生技全錄 v1.10](docs/source/神洲三國_軒轅天生技全錄_v1.10.md)

兩份原檔是遊戲設定權威；需求、技術方案、里程碑與測試是工程規格。原檔未提供完整人物資料庫、事件日期、地圖、經濟數值及機率公式。示例資料不得冒充完整歷史資料。

## 本機啟動

需要 Node.js 20.19+ 或 22.12+。在倉庫根目錄執行：

```sh
npm ci
npm run dev
```

依 Vite 顯示的網址開啟遊戲。驗證指令：

```sh
npm run typecheck
npm test
npm run build
```

## 第一階段實作與驗收

原型可預覽姓名、出生地、家庭與種子抽樣結果，確認後建立獨立世界線；可玩 20 個季度回合，前十回合構成 ROADMAP 的可玩段落。每回合選一項互斥生活意圖、查看天下大勢及後台示例，第 5、10、15、20 回合產生摘要。存檔使用 IndexedDB，支援切換世界線及 JSON 匯入匯出。引擎使用版本化命令、事件、revision 與確定性狀態轉移，並可由事件重播。

| 項目 | 結果 | 實際覆蓋 |
|---|---|---|
| ROADMAP 第一階段出口 | 原型範圍通過 | 開局確認、獨立世界線、地方生活、互斥選項、逐回合天下大勢、摘要、存讀檔；四引擎各有明示為示例的小型案例。 |
| A01 | 通過 | 固定種子與命令重播十回合狀態、事件及重播結果一致；不同意圖產生不同結果。 |
| A02 | 通過 | 新局不承接舊角色狀態；多 slot 保留舊存檔與事件流。 |
| A03 | 通過（規格範圍） | 依原檔 30 類出生地表與最近三次去重；姓氏依最近開局紀錄去重；確認前顯示結果且不暗換種子。姓氏候選池是示例，並非史料機率表。 |
| A04 | 通過 | 重送相同 commandId 不重結算；重用 ID 或過期 revision 會被拒絕。 |
| A05 | 通過（故障注入） | IndexedDB 結構化複製失敗後，舊存檔與 profile 可重載；UI 保留原狀態並顯示錯誤。未做真實瀏覽器斷電測試。 |
| A06 | 通過 | 有效 JSON 可驗證、匯入、重載與重播；毀損內容、未知版本及不同內容的重複 slot 均遭拒絕。 |
| A07 | 通過 | 5／10／15／20 摘要類型正確，10／20 不重複小記；每回合檢查人事、人才、歷史、天下引擎並產生趨勢。 |
| A11 | 通過（小型案例） | 私帳支出、公帳收入可追溯；物資代管不轉移所有權、不改數量，重複代管不增量。完整帳務／藏界玩法尚未接入。 |
| A27 | 通過 | 四項互斥意圖各有單一主向；「繼續」不推進時間、不批准待決事項。 |

驗收行為測試共 12 項，涵蓋 `src/engine.test.ts` 與 `src/storage.test.ts`。最近檢查：`npm run typecheck` 通過；`npm test` 通過（2 個測試檔、12 項）；`npm run build` 通過。

## 尚未完成

- 人事、人才、歷史節點、天下大勢僅有可運作的小型示例，不是完整歷史人物名冊、事件庫或史實模擬。
- 自由文字行動解讀未支援；敘事使用繁中範本，不接付費 AI、不需要金鑰。
- 天生技以 v1.10 為設定基準，但完整能力目錄與效果尚未實作；不宣稱能力已發動，也未擅加消耗、冷卻或副作用。
- 完整家庭／關係圖、軍政戰爭、完整帳務與藏界互動、更多人生階段仍未完成。本次未開始第二階段，也未部署。
