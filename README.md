## 遊戲定位

單人、繁體中文、章回小說式的三國人生與世界模擬遊戲。玩家從出生、家庭與成長開始，可走平民、商人、遊俠、仕宦、軍政或帝王路線；不強迫統一天下。主角具有現代記憶及原檔指定的超自然天生技，其他人物與制度則持續遵循世界規則。遊戲重點是選擇、關係、後果與持續運作的世界。

## 文件順序

## 範圍與可信度

兩份原檔是遊戲設定權威；本包的資料結構、演算法、畫面、里程碑與測試是工程建議。原檔未提供完整歷史人物資料庫、所有事件日期、地圖資料、經濟數值與機率公式；不能把這些缺口當成已完成內容。開發時以有來源的資料包逐批補齊，測試人物與示例數值須標註。

規格涵蓋完整目標，但第一階段刻意只做可驗證的小型遊戲。每階段介面應清楚標示未完成內容，不能把簡化原型稱為完整三國模擬。
