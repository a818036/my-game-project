## 啟動與檢查

需要 Node.js 20.19+ 或 22.12+。在倉庫根目錄執行：

先開兩個終端機。在第一個啟動本機敘事代理（預設 mock、不用金鑰）：

```sh
npm ci
npm run narration
```

第二個終端機啟動遊戲：

```sh
npm run dev
```

依 Vite 顯示的網址開啟遊戲，通常是 `http://localhost:5173`。Windows PowerShell 若 `npm` 指到受執行原則限制的 `npm.ps1`，請用：

```powershell
npm.cmd ci
npm.cmd run narration
```

第一個視窗會持續執行代理。另開第二個 PowerShell 視窗：

```powershell
npm.cmd run dev
```

檢查指令：`npm run typecheck`、`npm test`、`npm run build`。

2026-10-30 已由 GitHub 乾淨複製分支驗證 `npm ci`、mock 敘事代理與 Vite 首頁可啟動（A319）；這不取代未參與開發玩家的實際試玩。

敘事代理預設只接受 `http://localhost:5173` 與 `http://127.0.0.1:5173`。若 Vite 因預設連接埠被占用而改用其他連接埠，請在代理視窗明確加入實際網址來源後重啟代理；例如 Vite 顯示 `http://127.0.0.1:5174` 時，在 Windows PowerShell 執行：

```powershell
$env:NARRATION_ALLOWED_ORIGINS = 'http://localhost:5174,http://127.0.0.1:5174'
npm.cmd run narration
```

只列出自己正在使用的本機網址，不要設為萬用來源 `*`。A320–A321 在乾淨副本驗證詢問與行動；本機 mock 不需金鑰，也不代表真實模型品質驗收。

## 敘事代理設定、資料範圍與限制

可複製 `.env.example` 作為非機密設定參考；伺服器預設 `NARRATION_PROVIDER=mock`。可調 `NARRATION_PORT`、`NARRATION_PROVIDER=mock|openai`、`NARRATION_MODEL`、`NARRATION_MAX_OUTPUT_TOKENS`（128–4000）及每個代理程序的 `NARRATION_MAX_PROVIDER_REQUESTS`（1–100，含自動重試；預設 10，重啟程序歸零）。`/api/health` 顯示剩餘供應者請求數。金鑰只放伺服器程序環境變數 `OPENAI_API_KEY`，不可放前端、Git 或聊天。實作使用 OpenAI [Responses API](https://platform.openai.com/docs/api-reference/responses)，預設模型 `gpt-4.1-mini`。API token 依模型輸入／輸出用量計費；非正式估算及假設見下方驗收準備文件與官方[目前價格表](https://developers.openai.com/api/docs/pricing)。開發驗證只用 mock 和假回應，沒有真實付費請求。

自由文字解析請求會包含玩家本次 textarea 原文、已勾選意圖，以及可選人物的識別碼／姓名／在世／在場／可招攬狀態；它不含死亡節點介入窗口、主權條約草案、天生技清冊或後台技能狀態。旁白請求只含最近已結算行動摘要、場景所在地、主角已知事實、玩家視野消息，以及在場 NPC 姓名／年齡／官職和各自已知事實。獨立對話請求會包含玩家本次對話文字、所在地、主角年齡、指定在場 NPC 的姓名／身份／個人已知事實，以及僅與該 NPC 的最近四次已保存往返文字；不傳天下消息、其他 NPC 私密知識、完整存檔或天生技後台。mock 對話回固定範本，不呼叫模型。代理不記錄請求正文。這是原型的資料最小化，不代表供應者不會保留已收到的資料；真實測試前請檢視其當前資料政策。

本機 mock 試玩：終端機一執行 `npm.cmd run narration`，終端機二執行 `npm.cmd run dev`，再開 Vite 網址。伺服器不在時，操作仍會結算；敘事區顯示範本與錯誤，提供重試。重試只重送相同事件批次，不再次推進遊戲。

Windows PowerShell 選擇真實 OpenAI 介面時（此操作可能產生費用，模型名可換）：

```powershell
$env:NARRATION_PROVIDER = 'openai'
$env:NARRATION_MODEL = 'gpt-4.1-mini'
$env:NARRATION_MAX_OUTPUT_TOKENS = '900'
$env:NARRATION_MAX_PROVIDER_REQUESTS = '10'
$secureKey = Read-Host '在本機輸入供應者 API 金鑰' -AsSecureString
$env:OPENAI_API_KEY = [System.Net.NetworkCredential]::new('', $secureKey).Password
npm.cmd run narration
# 結束代理後清除目前 PowerShell 程序的環境變數
Remove-Item Env:OPENAI_API_KEY
```

不要把金鑰貼到聊天或放入 `.env`；這段設定只在本機程序記憶體中使用。

對 `gpt-4.1-mini` 的預估僅供規劃：官方價格頁（查閱日 2026-10-21）列標準輸入 `$0.40`／百萬 token、輸出 `$1.60`／百萬 token（快取輸入另計）。若一個行動解析＋旁白回合合計約 2,700 輸入 token、且兩次輸出都用滿 900 token，估算約 `$0.0040` 美元；5 組、每組最多解析＋旁白共 10 次請求，若每次平均 2,000 輸入 token 且輸出上限均用滿，約 `$0.0224` 美元。這是假設值，不含額外重試與價格變動，不是費用保證。將 `NARRATION_MAX_PROVIDER_REQUESTS=10` 限定單次伺服器程序最多 10 次外呼、輸出上限設為 900；每次外呼最多有一次短暫錯誤重試，重試也計入上限。

戰場視線與有限因果鏈距離支援 3D 高程，並標示場景座標採公尺或正規化單位；舊 2D 場景把缺少的高度視為 0。這是可重播的幾何估算，公尺標記不代表示例座標已按史實測量，亦不包含真實地形、天候、碰撞或受力推算。v3.17 §9.3C 是敘事規則，並不要求完整物理引擎；旁白提示現已列明七項要求與不虛構限制，但戰役場景資料覆蓋和真實模型文風仍待驗收。
