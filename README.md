# 神洲三國：Phase 2 人生與資訊原型

規則基準：規則手冊 **v3.15**、軒轅天生技全錄 **v1.10**。兩份原始手冊保留於 `docs/source/`，來源及 SHA-256 記錄於 `SOURCE_MANIFEST.json`。原檔未提供完整人物資料庫、事件日期、地圖、經濟數值及機率公式；本原型明示標註的內容只是少量示例。

## 啟動與檢查

需要 Node.js 20.19+ 或 22.12+。在倉庫根目錄執行：

```sh
npm ci
npm run dev
```

依 Vite 顯示的網址開啟遊戲，預設為 `http://localhost:5173`。Windows PowerShell 若把 `npm` 解析為受執行原則限制的 `npm.ps1`，可改用 `npm.cmd ci`、`npm.cmd run dev`；命令提示字元則使用一般 `npm` 指令。

```sh
npm run typecheck
npm test
npm run build
```

## Phase 1 保留範圍

可確認名字、出生年、種子與抽樣結果，建立獨立世界線；四項互斥生活意圖每回合只選一項。天下大勢與人事、人才、歷史、天下後台每回合自動更新；五、十、十五、二十回合產生摘要。存檔使用 IndexedDB，支援多世界線、JSON 匯入匯出、版本化事件重播。Phase 1 的開局、生活、摘要與存檔功能及事件歷史仍在。

## Phase 2 可操作功能

- 家庭圖可新增血親、收養、婚姻及玩家命名人物；關係稱謂由圖譜路徑推得。死亡者保留在人物紀錄中，並退出在場名單。
- 潛力與成熟五維分開。角色滿十五歲後可明確確認「原型評估」；因原文沒有成年公式，測試起值會沿用潛力並留下版本註記。五維限制 1–100；普通核心技能最多五項，天生技獨立列管。
- 信任、忠誠、恐懼各自增減，恩怨另存具體紀錄。
- 錢、糧、貨物、馬匹、書籍分帳；每筆移轉記錄來源、去向、回合與事由。錢帳與既有私帳同步。物品所有人與保管人／位置分開記錄。
- 場景顯示在場、進場、離場人物；每回合第一次發言標出整歲年齡與官職。同回合後續發言只列姓名。傳音示例是主角至收件者的單向記錄；書信示例兩回合後抵達，不會自動生成回覆。
- 傷勢會跨回合累積時間，只有玩家明確記錄處置才結束。十五／二十回合摘要沿用 Phase 1 小記／大記規則。
- 詳細家庭、成長、關係、帳務、通訊與傷勢面板可收合；回合敘事與天下大勢仍在主要閱讀區。

## 存檔遷移與驗收

新版存檔為 v3。既有 v2 世界線會先驗證完整事件重播，再增加升級事件；原事件前綴不變，原 v2 檔另存於 IndexedDB `profile` 中的遷移封存鍵。舊進度（含已達舊版第 20 回合的世界線）升級後可繼續至新版上限。JSON 匯入也支援同一升級流程；匯入前會保留原 v2 檔案內容作遷移封存。

目前驗收結果：

| 項目 | 結果 | 覆蓋行為 |
|---|---|---|
| ROADMAP Phase 1 出口 | 保留 | 開局、獨立世界線、生活回合、四項意圖、摘要、IndexedDB、JSON、事件重播。 |
| A01–A07 | 通過 | 固定種子重播、世界線隔離、抽樣去重、命令冪等、存檔故障保全與 JSON 往返、五／十／十五／二十摘要和四引擎自動檢查。 |
| A08 | 通過（公式明示為原型假設） | 五維範圍 1–100、技能最多五項、天生技另列；成年起值不冒充原文規則。 |
| A09 | 通過 | 姓名未由玩家確認前，人物只在待命名佇列、不進入家庭圖。 |
| A10 | 通過（小型案例） | 血親、收養、婚姻、跨年齡代際稱謂與死亡留檔。複雜旁系稱謂仍非完整規則庫。 |
| A11 | 通過 | Phase 1 五類錢帳延續；Phase 2 加入多資產流水、錢帳同步及物權／保管分離。 |
| A12 | 通過 | 人為錯置餘額後，可由可靠錢帳流水事件重算五帳、角色私錢與 Phase 2 私帳；重算不新增補差額流水，且可從事件重播還原。 |
| A13 | 通過（規則示例） | 傳音不產生對方回話；書信需兩回合抵達。完整天生技通訊範圍未實作。 |
| A14 | 通過 | 每回合場景名單及進離場可見；首發言有年齡／官職，同回合重複稱名不重複標註。 |
| A25 | 通過（後台小案例） | 玩家只選地方生活時，第 15／16 回合仍自動出現佐吏死亡與接任案例及各引擎檢查。 |
| A28 | 通過（資訊邊界示例） | 目擊者只存當次可見現象，不取得能力名稱、容量或限制。 |
| v2 舊存檔遷移 | 通過 | 10 回合進度遷移後續至 11；已完成 20 回合舊存檔亦可推進至 21；舊事件流封存與重播相符。 |

最後檢查：`npm run typecheck` 通過；`npm test` 通過（2 個測試檔、22 項）；`npm run build` 通過。
