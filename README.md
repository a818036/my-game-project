# 神洲三國：第五階段開發中原型

2026-10-28 情境更新：輸入先分成詢問、質疑、對話、明確行動、混合或不明；純詢問／質疑不推進時間，也不會執行先前勾選。無法判定的句子會要求拆開。嬰幼兒、幼童與少年顯示觀察、聆聽、整理記憶、休息等在地日常選項；每項可選 1／7／30／90 日安排，一份計畫仍只跑一次後台。保留的舊事件可照錄重播，但新介面不允許未成年直接使用成人生活行動。年齡隨世界日曆同步；天生技仍按各自規則處理。

規則基準為規則手冊 v3.15、軒轅天生技全錄 v1.10。兩份原始手冊保留於 `docs/source/`，SHA-256 記錄在 `SOURCE_MANIFEST.json`；不完整人物、歷史事件、地理與公式以明示的示例或可調工程參數呈現。

## 啟動與檢查

需要 Node.js 20.19+ 或 22.12+。在倉庫根目錄執行：

先開兩個終端機。在第一個啟動本機敘事代理（預設 mock、不用金鑰）：

```sh
npm ci
npm run narration
```

第二個終端機啟動遊戲：

```sh
npm run dev
```

依 Vite 顯示的網址開啟遊戲，通常是 `http://localhost:5173`。Windows PowerShell 若 `npm` 指到受執行原則限制的 `npm.ps1`，請用：

```powershell
npm.cmd ci
npm.cmd run narration
```

第一個視窗會持續執行代理。另開第二個 PowerShell 視窗：

```powershell
npm.cmd run dev
```

檢查指令：`npm run typecheck`、`npm test`、`npm run build`。

## 已完成的可玩內容

- **第一階段骨架**：繁中開局、出生確認、固定／隨機種子、獨立世界線、地方生活、天下大勢與第 5／10／15／20 回合摘要。現行旅程上限 120 回合，讓 184 年開局可經正常行動抵達 190／191 年歷史節點。後台人事、人才、歷史與天下引擎各有可玩的示例；未宣稱已有完整歷史資料庫。
- **行動計畫覆寫**：四個行動改為可複選 checkbox，另有「補充說明」textarea 與「送出行動」。相容行動依一份計畫、共用一回合與一次後台推進結算；衝突列出原因；未解析文字保存為備註，不會假稱執行。命名、主權與結局仍由各自明確確認。
- **第五階段自由文字候選**：補充文字可單獨提交或補充 checkbox。mock 模式使用本機確定性詞彙解析器；支援「耕讀／讀書／讀兵書／耕作」、「訪求人才／招攬／延請」、「經商／做生意／買賣／市集」、「遊歷／拜訪／探望」等有限詞彙、明確先後、已知且在場人物拜訪、目前登錄人才招攬及「目標仍在場」條件。`openai` 模式會把本次原文及允許目標送到真實 Responses API，要求 JSON Schema 結構化候選；輸出仍限四項行動，由本機檢查目標／意圖／衝突並要求玩家確認，再交規則引擎結算。語意解析比 mock 寬，但不支援天生技施放、死亡救援、任命／戰爭等軍政命令、永久條約、命名、結局及無法驗證的條件。否定、歧義、衝突或供應者解析失敗會顯示澄清／本機回退，不假稱執行。
- **第五階段敘事服務**：`server/` 提供本機代理，預設 mock、無金鑰。遊戲交易成功後才呼叫旁白；旁白只潤飾結算資料，不解析行動、不修改規則狀態。敘事失敗、取消或重試不重跑回合。AI 欄位、發言者及數字事實有驗證，失敗回退範本。前端不含 API 金鑰。
- **第二階段**：家庭血親／收養／婚姻圖譜與玩家命名、五維成長、分離記錄的信任／忠誠／恐懼／恩怨、多資產帳簿、所有權／保管分離、在場與單向通訊、持續傷勢。
- **天生技操作**：可從收合的操作台使用 v1.10 全部 46 項正式能力／通則與七種組合式的專屬入口，設定適用的目標、排除者、強度、幻術分發／深度與致命意圖；引擎記錄直接、次生、持續、解除及恢復結果。小型人物、部隊、物件、語言與場景明確標記為示例，不冒充完整資料庫。逐項原文位置、實作狀態與行為證據見 [能力覆蓋表](docs/ABILITY_COVERAGE.md)。
- **已驗證案例**：幻術分發×深度、非致命／致命界線、威壓即時壓制與持續創傷、伏地累傷／解除／恢復、七種雷霆結構化環境與持續雷域、治療生理恢復／疾病／回春／百脈、傳音／共視／多領域條件推演、藏界與軒轅閃、萬解、極限收斂、人心／人才線索／部隊統御及七種能力組合。環境距離、病程、創傷緩和、恢復與生理換算中原文未給定的數值均標示為可調工程參數。
- **存檔**：IndexedDB 自動保存、JSON 匯入匯出、命令事件重播。現行 JSON 格式 v6；v2–v5 會保留舊事件前綴並追加版本化遷移事件，讓舊進度可續玩。第四階段 v6 現有存檔另有載入、續玩、重播、匯出驗證及再次儲存的 round-trip 回歸測試。
- **閱讀介面**：東漢末年敘事採米白紙面、墨色文字、深木與朱紅點綴，保留對比及留白，不使用書法正文。預設正文 18px／行高 1.7，控制至少 16px；16–24px 字級偏好保存於瀏覽器。手機與桌面支援換行與窄螢幕排版。

- **第四階段歷史／軍政案例**：分開年級死亡硬節點與一般史實事件；逐年跨期結算死亡、因果取消、官職到任／繼任、人才拒絕／勢力競爭、政策月結、五層地方控制、普通驛路運輸、逐輪戰役、撤退，以及須明確批准的主權條款和統一後人生選擇。死亡窗口依事件 ID 個別設定；孫堅示例的 30 模型日是可調工程參數，未設定窗口的事件不會繼承。軍政資料放在收合面板。條約草案需指定領地與承接控制者；玩家明確批准或逐條匹配的授權才實際改變領地控制者。
- **內容來源與資料界線**：目前只有一個年級精度的關東州郡事件與孫堅死亡節點；史料引文、精度及示例情境列於 [第四階段內容表](docs/HISTORY_CONTENT.md)。地方、職缺、人才、路線、戰役及數值明確標為示例／工程參數，不宣稱完整收錄三國世界。
- **時間與資料遷移**：事件引擎 v5／存檔 v6；Phase 3 舊存檔透過追加遷移事件保留事件前綴與進度。以往存檔可繼續，仍建議先匯出 JSON 備份。

## 敘事代理設定、資料範圍與限制

可複製 `.env.example` 作為非機密設定參考；伺服器預設 `NARRATION_PROVIDER=mock`。可調 `NARRATION_PORT`、`NARRATION_PROVIDER=mock|openai`、`NARRATION_MODEL`、`NARRATION_MAX_OUTPUT_TOKENS`（128–4000）及每個代理程序的 `NARRATION_MAX_PROVIDER_REQUESTS`（1–100，含自動重試；預設 10，重啟程序歸零）。`/api/health` 顯示剩餘供應者請求數。金鑰只放伺服器程序環境變數 `OPENAI_API_KEY`，不可放前端、Git 或聊天。實作使用 OpenAI [Responses API](https://platform.openai.com/docs/api-reference/responses)，預設模型 `gpt-4.1-mini`。API token 依模型輸入／輸出用量計費；非正式估算及假設見下方驗收準備文件與官方[目前價格表](https://developers.openai.com/api/docs/pricing)。開發驗證只用 mock 和假回應，沒有真實付費請求。

自由文字解析請求會包含玩家本次 textarea 原文、已勾選意圖，以及可選人物的識別碼／姓名／在世／在場／可招攬狀態；它不含死亡節點介入窗口、主權條約草案、天生技清冊或後台技能狀態。旁白請求只含最近已結算行動摘要、場景所在地、主角已知事實、玩家視野消息，以及在場 NPC 姓名／年齡／官職和各自已知事實。獨立對話請求只含玩家對話文字、所在地、主角年齡和指定在場 NPC 的姓名／身份／個人已知事實；不傳天下消息、其他 NPC 私密知識、完整存檔或天生技後台。mock 對話回固定範本，不呼叫模型。代理不記錄請求正文。這是原型的資料最小化，不代表供應者不會保留已收到的資料；真實測試前請檢視其當前資料政策。

本機 mock 試玩：終端機一執行 `npm.cmd run narration`，終端機二執行 `npm.cmd run dev`，再開 Vite 網址。伺服器不在時，操作仍會結算；敘事區顯示範本與錯誤，提供重試。重試只重送相同事件批次，不再次推進遊戲。

Windows PowerShell 選擇真實 OpenAI 介面時（此操作可能產生費用，模型名可換）：

```powershell
$env:NARRATION_PROVIDER = 'openai'
$env:NARRATION_MODEL = 'gpt-4.1-mini'
$env:NARRATION_MAX_OUTPUT_TOKENS = '900'
$env:NARRATION_MAX_PROVIDER_REQUESTS = '10'
$secureKey = Read-Host '在本機輸入供應者 API 金鑰' -AsSecureString
$env:OPENAI_API_KEY = [System.Net.NetworkCredential]::new('', $secureKey).Password
npm.cmd run narration
# 結束代理後清除目前 PowerShell 程序的環境變數
Remove-Item Env:OPENAI_API_KEY
```

不要把金鑰貼到聊天或放入 `.env`；這段設定只在本機程序記憶體中使用。

對 `gpt-4.1-mini` 的預估僅供規劃：官方價格頁（查閱日 2026-10-21）列標準輸入 `$0.40`／百萬 token、輸出 `$1.60`／百萬 token（快取輸入另計）。若一個行動解析＋旁白回合合計約 2,700 輸入 token、且兩次輸出都用滿 900 token，估算約 `$0.0040` 美元；5 組、每組最多解析＋旁白共 10 次請求，若每次平均 2,000 輸入 token 且輸出上限均用滿，約 `$0.0224` 美元。這是假設值，不含額外重試與價格變動，不是費用保證。將 `NARRATION_MAX_PROVIDER_REQUESTS=10` 限定單次伺服器程序最多 10 次外呼、輸出上限設為 900；每次外呼最多有一次短暫錯誤重試，重試也計入上限。
