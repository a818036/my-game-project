# 神洲三國：第五階段開發中原型

規則基準為規則手冊 v3.15、軒轅天生技全錄 v1.10。兩份原始手冊保留於 `docs/source/`，SHA-256 記錄在 `SOURCE_MANIFEST.json`；不完整人物、歷史事件、地理與公式以明示的示例或可調工程參數呈現。

## 啟動與檢查

需要 Node.js 20.19+ 或 22.12+。在倉庫根目錄執行：

先開兩個終端機。在第一個啟動本機敘事代理（預設 mock、不用金鑰）：

```sh
npm ci
npm run narration
```

第二個終端機啟動遊戲：

```sh
npm run dev
```

依 Vite 顯示的網址開啟遊戲，通常是 `http://localhost:5173`。Windows PowerShell 若 `npm` 指到受執行原則限制的 `npm.ps1`，請用：

```powershell
npm.cmd ci
npm.cmd run narration
```

第一個視窗會持續執行代理。另開第二個 PowerShell 視窗：

```powershell
npm.cmd run dev
```

檢查指令：`npm run typecheck`、`npm test`、`npm run build`。

## 已完成的可玩內容

- **第一階段骨架**：繁中開局、出生確認、固定／隨機種子、獨立世界線、地方生活、天下大勢與第 5／10／15／20 回合摘要。現行旅程上限 120 回合，讓 184 年開局可經正常行動抵達 190／191 年歷史節點。後台人事、人才、歷史與天下引擎各有可玩的示例；未宣稱已有完整歷史資料庫。
- **行動計畫覆寫**：四個行動改為可複選 checkbox，另有「補充說明」textarea 與「送出行動」。相容行動依一份計畫、共用一回合與一次後台推進結算；衝突列出原因；未解析文字保存為備註，不會假稱執行。命名、主權與結局仍由各自明確確認。
- **第五階段自由文字候選**：補充文字可單獨提交或補充 checkbox。支援範圍是四種地方生活意圖的明確詞彙、先後順序、已知且在場人物拜訪、目前登錄人才招攬，以及「目標仍在場」條件。每項文字行動先顯示候選並要求玩家確認，再由引擎驗證／結算；否定、含糊、衝突、未支援能力與重大主權／命名／結局意圖不會通用執行。完全無法解析時只能存為備註，不推進時間或資源。
- **第五階段敘事服務**：`server/` 提供可替換的本機代理，預設 mock、無金鑰。遊戲交易成功後才傳送去除自由文字原文的結算資料；敘事失敗、取消或重試不重跑回合。AI 欄位不能修改規則狀態；在場發言者及數字事實有前後端檢查，另以範本回退。前端不含 API 金鑰。
- **第二階段**：家庭血親／收養／婚姻圖譜與玩家命名、五維成長、分離記錄的信任／忠誠／恐懼／恩怨、多資產帳簿、所有權／保管分離、在場與單向通訊、持續傷勢。
- **天生技操作**：可從收合的操作台使用 v1.10 全部 46 項正式能力／通則與七種組合式的專屬入口，設定適用的目標、排除者、強度、幻術分發／深度與致命意圖；引擎記錄直接、次生、持續、解除及恢復結果。小型人物、部隊、物件、語言與場景明確標記為示例，不冒充完整資料庫。逐項原文位置、實作狀態與行為證據見 [能力覆蓋表](docs/ABILITY_COVERAGE.md)。
- **已驗證案例**：幻術分發×深度、非致命／致命界線、威壓即時壓制與持續創傷、伏地累傷／解除／恢復、七種雷霆結構化環境與持續雷域、治療生理恢復／疾病／回春／百脈、傳音／共視／多領域條件推演、藏界與軒轅閃、萬解、極限收斂、人心／人才線索／部隊統御及七種能力組合。環境距離、病程、創傷緩和、恢復與生理換算中原文未給定的數值均標示為可調工程參數。
- **存檔**：IndexedDB 自動保存、JSON 匯入匯出、命令事件重播。現行 JSON 格式 v6；v2–v5 會保留舊事件前綴並追加版本化遷移事件，讓舊進度可續玩。
- **閱讀介面**：東漢末年敘事採米白紙面、墨色文字、深木與朱紅點綴，保留對比及留白，不使用書法正文。預設正文 18px／行高 1.7，控制至少 16px；16–24px 字級偏好保存於瀏覽器。手機與桌面支援換行與窄螢幕排版。

- **第四階段歷史／軍政案例**：分開年級死亡硬節點與一般史實事件；逐年跨期結算死亡、因果取消、官職到任／繼任、人才拒絕／勢力競爭、政策月結、五層地方控制、普通驛路運輸、逐輪戰役、撤退，以及須明確批准的主權條款和統一後人生選擇。死亡窗口依事件 ID 個別設定；孫堅示例的 30 模型日是可調工程參數，未設定窗口的事件不會繼承。軍政資料放在收合面板。條約草案需指定領地與承接控制者；玩家明確批准或逐條匹配的授權才實際改變領地控制者。
- **內容來源與資料界線**：目前只有一個年級精度的關東州郡事件與孫堅死亡節點；史料引文、精度及示例情境列於 [第四階段內容表](docs/HISTORY_CONTENT.md)。地方、職缺、人才、路線、戰役及數值明確標為示例／工程參數，不宣稱完整收錄三國世界。
- **時間與資料遷移**：事件引擎 v5／存檔 v6；Phase 3 舊存檔透過追加遷移事件保留事件前綴與進度。以往存檔可繼續，仍建議先匯出 JSON 備份。

## 範圍及未完成項目

第四階段提供小型可玩的歷史與軍政切片，不是完整三國沙盒。現有雙線案例已實作指揮分工、唯一部隊位置、兵力守恆與跨線調動；未完成的是多戰區內容規模、逐兵模擬、完整敵軍 AI、天候／地形全資料。政策不是完整稅制或市場模型。史實人物與事件只列有來源的少量案例；示例名稱、日期精度及未完成內容列在 [第四階段內容表](docs/HISTORY_CONTENT.md)。

第五階段目前已完成本機 mock 與結構／邊界驗證，但**真實 AI 供應者未連線驗證**，故不宣稱第五階段完整驗收。自由文字採確定性窄範圍解析器，不是任意自然語言理解；完整條件句、談判／軍政／技能指令與長期行動仍未支援。NPC 對話和長篇小說需真實模型與人工遊玩評估；目前 mock 是短篇結果潤飾範本。代表性人工檢視記錄於 [敘事品質評估](docs/NARRATION_EVALUATION.md)。

第三階段逐能力細節與缺口分類見 [docs/ABILITY_COVERAGE.md](docs/ABILITY_COVERAGE.md)，驗收案例見 [docs/ACCEPTANCE.md](docs/ACCEPTANCE.md)。若清冊仍列原文明定直接效果未完成，PR 不得以測試通過數量宣稱第三階段出口已完成。

## 敘事代理設定、資料範圍與限制

可複製 `.env.example` 作為設定參考；伺服器預設 `NARRATION_PROVIDER=mock`。可調 `NARRATION_PORT`、`NARRATION_PROVIDER=mock|openai`、`NARRATION_MODEL`、`NARRATION_MAX_OUTPUT_TOKENS`（128–4000）。要測真實連線時，將金鑰安全地放在伺服器程序的 `OPENAI_API_KEY` 環境變數；不要放在 Vite 前端變數、Git 或聊天。OpenAI 使用 [Responses API](https://platform.openai.com/docs/api-reference/responses)，真實請求可能按供應者計價；專案不會自動呼叫付費模型，也未在開發期間進行真實付費測試。

敘事請求只含最近一筆已結算行動摘要、場景所在地、主角記錄的已知事實，以及在場 NPC 的姓名／年齡／官職和其個別觀察；天下大勢只屬玩家視野。原始補充文字、種子、存檔、帳簿、完整人物圖譜、其他地點人物及技能後台不送往模型。代理不記錄請求內容。這是原型的資料最小化，不代表遠端供應者完全不保留其收到的請求；真實使用前請查閱其當前資料政策。

本機 mock 試玩：終端機一執行 `npm.cmd run narration`，終端機二執行 `npm.cmd run dev`，再開 Vite 網址。伺服器不在時，操作仍會結算；敘事區顯示範本與錯誤，提供重試。重試只重送相同事件批次，不再次推進遊戲。

Windows PowerShell 選擇真實 OpenAI 介面時（此操作可能產生費用，模型名可換）：

```powershell
$env:NARRATION_PROVIDER = 'openai'
$env:NARRATION_MODEL = 'gpt-4.1-mini'
$env:NARRATION_MAX_OUTPUT_TOKENS = '900'
$secureKey = Read-Host '在本機輸入供應者 API 金鑰' -AsSecureString
$env:OPENAI_API_KEY = [System.Net.NetworkCredential]::new('', $secureKey).Password
npm.cmd run narration
# 結束代理後清除目前 PowerShell 程序的環境變數
Remove-Item Env:OPENAI_API_KEY
```

不要把金鑰貼到聊天或放入 `.env`；這段設定只在本機程序記憶體中使用。
