# PR #6 第六階段繁體中文導讀

PR #6「第六階段：歷史內容與無障礙基礎」仍在審查中，尚未合併，也沒有部署網站。這份文件將大量英文提交整理成繁體中文主題摘要，方便先掌握工作範圍。

**這是主題整理，不是逐筆提交翻譯。** GitHub 顯示 PR 已累積數百筆提交，標題多為英文；舊提交標題與 SHA 保留不動。PR 的一般留言及審查留言目前皆為 0。

## 這個 PR 做了什麼

### 本輪新增

- 年份史實查詢新增指定人物篩選：例如詢問曹操在 198 年的事，只列來源敘述明確包含曹操的節點；劉備同年沒有命中時明示資料缺口，不拿別人的事件代答。此功能只覆蓋程式列出的有限人物名稱，不代表完整人物年表。
- 查核 CHGIS V6 與中研院 CCTS 官方授權頁：前者限學術使用並禁止商業使用、轉售與再散布；後者底圖整合受著作權保護的歷史圖資及 Arc/China，只提供特定機構／個人學術用途，未授權公開再散布。專案尚未取得另行授權，因此不匯入或鏡像其縣級座標／疆界；完整地理資料仍待找到允許本專案發布的來源。
- A276 新增減少動態效果偏好的 CSS 回歸檢查：核對平滑捲動停用、動畫與轉場縮為 .01ms；不同作業系統與瀏覽器的實際行為仍待抽查。
- A277 加強戰場敘事提示與契約測試，逐項核對 §9.3C 七項敘事要求及「資料不足不虛構」邊界；這只驗證指令已傳入，不代表真實模型已遵守或各戰役都有足夠資料。
- A278 將 ChatGPT 訂閱登入按鈕改為繁體中文，並以模擬連線狀態的元件測試確認顯示文案。
- A279 為必要命名對話框關聯用途說明，並以元件 DOM 測試核對標題／說明關聯；實際螢幕閱讀器語音仍待人工驗收。
- A280 修正跳轉連結目的地原先被移除的焦點外框，使主要內容及開局表單落點可見；CSS 回歸測試涵蓋兩個落點與連結本身；App DOM 驗證開局與遊戲畫面的跳轉目標及可聚焦性。
- A281 讓初始化畫面載入文案成為可見的即時狀態訊息，伺服器渲染測試確認播報語意與文字。
- A282 在 Windows 強制色彩模式下，讓跳轉後的程式焦點落點明確使用系統高亮色；CSS 回歸測試確認選擇器與顏色。
- A283 讓開局保存進度也能透過持續存在的 `role="status"` 區域播報；DOM 測試確認更新文字時保留同一節點；App 整合測試實際操作出生確認與開局保存流程，確認等待及完成訊息都在介面播報。實際螢幕閱讀器語音仍待人工驗收。
- A284 讓 IndexedDB 開局讀取錯誤在出生確認畫面以 `role="alert"` 顯示及播報；SSR 測試核對錯誤文字與空訊息處理，React DOM 整合測試確認 IndexedDB 讀取失敗會在出生確認畫面顯示，正常載入不誤報；重試期間按鈕停用並顯示忙碌狀態，成功後清除錯誤且不覆寫存檔；若重試仍失敗，警示文字更新且按鈕恢復可用；警示區不包住互動按鈕；新局寫入失敗則不誤顯示讀取重試鈕；實際瀏覽器故障注入及螢幕閱讀器仍待人工驗收。
- A285 靜態 CSS 檢查確認對話紀錄長字串可斷行、正文維持 16px／1.6 行高；390px 實際視口仍待人工驗收。
- 最新完整回歸為 49 個測試檔、469 項全過；型別檢查及正式建置通過。固定長局基準推進中位數 5,057.0 ms／重播中位數 5,032.2 ms，仍只代表此桌面 CPU 的規則引擎執行時間。

### 本輪對話驗收更新

- A266 自動驗收通過：對話經 IndexedDB 保存、重新載入、續聊、匯入驗證及事件重播；事件前綴保持不變，日期、回合與人物關係不變。每人四次／全線四十次上限、只送同一人物最近四輪、每句 240 字節錄及超過 1,200 字時不呼叫服務均有測試。
- A267–A268 自動 DOM 驗收通過：對話紀錄以原生可展開清單呈現，資料說明與輸入欄透過 `aria-describedby` 關聯。實際螢幕閱讀器與窄螢幕手動檢查仍待完成。
- A269–A270 自動契約驗收通過：前端送粗略關係分檔而非原始數值，送出主角年齡／月齡；伺服器提示及輸入驗證保留相關邊界。不同年齡及關係情境的真實模型語意驗收仍待人工執行。

### 歷史事件與史料界線

- 補入 183–280 年間可供遊玩的來源支持事件與死亡節點，依資料採年級、月份或季節精度；不從年級資料推造日、時辰或私人日常。
- 對不同史書的日期與用字差異保留來源註記，避免同一件事重複結算；舊存檔升級以追加遷移處理，保留既有事件帳，也不把已過事件補觸發。
- 人物年表有資料的年份只列來源支持的紀錄；沒有收錄的年份明示資料缺口，不把「沒有資料」寫成「當年沒有事件」。
- 有一大批提交集中整理孫權年表與問答。孫權是這批內容中的史料索引對象，並非玩家主角；日常作息缺乏史料時會明說未記載，不補造內容。後續內容擴充應繼續以玩家主角的人生和可玩世界為中心。

### 東漢行政地名資料

- 增加十二州刺史部、司隸及郡縣名錄查閱切片，資料保留《後漢書》原文名稱、次序及異文說明。
- 現有名錄整理為 105 份、共 1,181 個縣、邑、公、侯國名目。這是跨時期來源索引，不是 184 年的完整疆界地圖，也不表示已具備縣級座標、道路或控制權模擬。

### 主角敘事、人物互動與 AI 邊界

- 旁白可參照存檔中近期已結算的主角行動，延續主角視角；NPC 只取得各自的觀察紀錄，不會自動共享主角私有情報。
- 在場 NPC 對話可跨重新整理保留，供同一人物延續話題；對話不推進回合、不改變關係。最近對話可在遊戲內回看。
- 即時對話新增信任、忠誠、畏懼的粗略分檔，只供輕微調整語氣；不傳原始分數或恩怨文字，也不得當成共同往事或關係變化。
- NPC 回話依主角年齡調整稱呼和解釋深度，兒少不會永遠被幼童化；年齡不會單獨推翻玩家輸入或創造特殊能力。送出前說明已列出年齡與所在地等傳送資料。
- 自由文字仍先形成可確認的行動候選；未支援或不明內容不會被假稱已執行。AI 敘事不能直接改動遊戲狀態。

### 戰場、存檔與操作介面

- 戰場示例加入三維視距／遮擋判斷，以及可選的具名軍籍傷亡狀態；結果仍依已登錄清冊及作用範圍。
- 新增受限球形剛體示例：明列公尺座標、半徑、質量與恢復係數後，可施加動量，再以自適應有限子步按既有速度推進並結算接觸、碰撞耗散、初始穿透修正及工程失效門檻。耗散平均分配及 80% 位置修正比例是工程假設；推進不含重力、外力或加速度，也不新增人員傷亡。這是有限工程示例；完整物理模擬不是 §9.3C 的必要出口條件。
- v6 剛體戰場事件已測試完整存檔往返：JSON 驗證匯入、IndexedDB 儲存與載入、再由事件前綴重播，狀態與原傷亡帳保持一致。
- 延續多版本存檔遷移與事件重播相容性，並量測 160–280 年歷史引擎的本機基準。量測是規則引擎時間，不等於瀏覽器渲染或低階裝置效能。
- 改善行動選項的語意群組、鍵盤焦點、閱讀字級與即時狀態播報；這些自動檢查仍不能取代完整螢幕閱讀器人工稽核。
- A273 加入 Windows 強制色彩模式支援：焦點、選取行動、目前分頁、跳轉連結與按鈕使用作業系統系統色。自動樣式檢查已加入；實際高對比模式仍待人工驗收。
- A274 結局改用可由 Enter 送出的原生表單；空白無效輸入仍會阻止提交。保存後焦點移至已記錄的結局結果，並以可見焦點框標示；自動 DOM 驗收已覆蓋送出、空白防護和焦點復原。
- A284／A287 實際處理內嵌瀏覽器存檔故障：`127.0.0.1:5174` 三份、`localhost:5174` 一份 v6 存檔無法通過事件重播，錯誤為保存狀態與事件不一致。逐份隔離後不再阻擋出生畫面；有效存檔與新局可使用，原始失效存檔保持不變並可下載 JSON 備份，同 ID 匯入遭拒以避免覆寫。錯誤細節可展開查看；沒有自動修補或下載任何使用者資料。
