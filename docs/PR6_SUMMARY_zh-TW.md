# PR #6 第六階段繁體中文導讀

PR #6「第六階段：歷史內容與無障礙基礎」仍在審查中，尚未合併，也沒有部署網站。這份文件將大量英文提交整理成繁體中文主題摘要，方便先掌握工作範圍。

**這是主題整理，不是逐筆提交翻譯。** GitHub 顯示 PR 已累積數百筆提交，標題多為英文；舊提交標題與 SHA 保留不動。PR 的一般留言及審查留言目前皆為 0。

## 這個 PR 做了什麼

### 歷史事件與史料界線

- 補入 183–280 年間可供遊玩的來源支持事件與死亡節點，依資料採年級、月份或季節精度；不從年級資料推造日、時辰或私人日常。
- 對不同史書的日期與用字差異保留來源註記，避免同一件事重複結算；舊存檔升級以追加遷移處理，保留既有事件帳，也不把已過事件補觸發。
- 人物年表有資料的年份只列來源支持的紀錄；沒有收錄的年份明示資料缺口，不把「沒有資料」寫成「當年沒有事件」。
- 有一大批提交集中整理孫權年表與問答。孫權是這批內容中的史料索引對象，並非玩家主角；日常作息缺乏史料時會明說未記載，不補造內容。後續內容擴充應繼續以玩家主角的人生和可玩世界為中心。

### 東漢行政地名資料

- 增加十二州刺史部、司隸及郡縣名錄查閱切片，資料保留《後漢書》原文名稱、次序及異文說明。
- 現有名錄整理為 105 份、共 1,181 個縣、邑、公、侯國名目。這是跨時期來源索引，不是 184 年的完整疆界地圖，也不表示已具備縣級座標、道路或控制權模擬。

### 主角敘事、人物互動與 AI 邊界

- 旁白可參照存檔中近期已結算的主角行動，延續主角視角；NPC 只取得各自的觀察紀錄，不會自動共享主角私有情報。
- 在場 NPC 對話可跨重新整理保留，供同一人物延續話題；對話不推進回合、不改變關係。最近對話可在遊戲內回看。
- 即時對話新增信任、忠誠、畏懼的粗略分檔，只供輕微調整語氣；不傳原始分數或恩怨文字，也不得當成共同往事或關係變化。
- 自由文字仍先形成可確認的行動候選；未支援或不明內容不會被假稱已執行。AI 敘事不能直接改動遊戲狀態。

### 戰場、存檔與操作介面

- 戰場示例加入三維視距／遮擋判斷，以及可選的具名軍籍傷亡狀態；結果仍依已登錄清冊及作用範圍，不代表完整碰撞、受力或物理傷亡模型。
- 延續多版本存檔遷移與事件重播相容性，並量測 160–280 年歷史引擎的本機基準。量測是規則引擎時間，不等於瀏覽器渲染或低階裝置效能。
- 改善行動選項的語意群組、鍵盤焦點、閱讀字級與即時狀態播報；這些自動檢查仍不能取代完整螢幕閱讀器人工稽核。
