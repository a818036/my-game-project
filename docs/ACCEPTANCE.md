- Chromium 內嵌頁面以 390×844 CSS viewport、24px 閱讀字級檢查完整遊戲畫面；文件寬 375px，沒有內容超出 viewport。Enter 啟動跳轉連結後焦點位於 `#main-content`；控制項有可讀名稱。這不是實機觸控或完整螢幕閱讀器審查。
- 長局效能基準可用 `npm run benchmark:history` 重現：固定種子從 160 年推進至 280 年（13 個事件），分別量測推進和事件重播；每項 2 次暖機、9 次取樣，列出中位數、p95、最低值與執行環境。本機 Node v24.20.0、Windows x64、Intel Core i5-6500 3.20GHz／4 邏輯核心結果：推進中位數 442.0ms、p95 716.7ms；重播中位數 409.6ms、p95 541.2ms。這是規則引擎量測，不含瀏覽器渲染；單一桌面環境結果不代表低階裝置，尚未訂正式效能門檻。
- 敘事上下文從已保存的行動紀錄提供最近五筆主角私人回憶，排除當次待敘事事件及未解析補充文字；不另存 AI 文句。觀察知識按知情者附回合、觀察摘要及已知 facts，unknown 不傳模型；NPC 仍只取得自己的明確觀察，且不得引用主角私人回憶或玩家視野。這是 v3.16 因果記憶的部分切片，尚未建立動機、誤讀、成本、消息傳播鏈或 NPC 長期記憶模型。
- 東漢行政參考目前可展開河南尹二十一城、潁川十七城與南陽三十七城來源名錄；只保留原文次序與用字，沒有把不同編纂時段拼成建安年份地圖，也沒有縣界、座標或控制權資料。
- 本次只建立第六階段的部分基線；完整地理資料、完整史實年表、正式效能門檻、全面無障礙或所有結局流程仍未驗收。
- A61 鍵盤焦點人工驗收：跳轉連結可將焦點送至主要內容；開啟勾選計畫後焦點進入有可讀標題的確認區，返回調整後回到原檢視按鈕，修改勾選時焦點保留在勾選項。使用 Chromium 內嵌頁面操作，未確認 NVDA／JAWS 等實際螢幕閱讀器輸出。

## 人工遊玩檢查

- 台灣繁中、章回敘事自然；角色性格不被統一成同一種口吻。
- 家事、遊歷、軍政都能推進，不強迫所有角色成為帝王或走固定主線。
- 主角親臨戰鬥有空間與因果，技能演出忠於原檔；不靠一句「大勝」跳過。
- 天下大勢簡短但有實質變化；未發生大事不虛構危機湊字數。
- 金錢、死亡、職位與地點可由紀錄追查；前台仍易讀，不被工程面板淹沒。
- 手機窄螢幕、鍵盤操作、長文捲動、存檔失敗與等待狀態可用。
- 敘事品質需另按 `docs/NARRATION_EVALUATION.md` 記錄人物聲音、繁中自然度、場景錨點與事實忠實度；mock、未帶金鑰的回退與真實模型評估分開標示。
- 真實供應者人工案例按 `docs/PHASE5_REAL_AI_ACCEPTANCE.md` 執行；無金鑰時只可標記為待驗證，不可把 fake adapter 結果當真實模型通過。

發布前另跑長局測試，涵蓋多次跨年、死亡與繼任、改朝換代、存檔遷移；記錄測試資料量、執行版本及失敗結果，不能只報告「測試通過」而不說測了什麼。
