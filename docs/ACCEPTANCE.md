- PR CI 另外檢查首頁 JavaScript 小於 500,000 bytes，延後載入戰役示例小於 10,000 bytes，並要求各自恰有一個 chunk。此為靜態建置預算，不能替代低階裝置或網路量測。
- PR CI 啟動隔離的 Vite 正式預覽伺服器，從首頁取得主要 JavaScript、CSS 及延後載入的戰役示例 chunk，確認回應為 HTTP 200 且內容類型正確；測試伺服器結束後即關閉，不部署也不接觸使用者瀏覽器資料。

## 人工遊玩檢查

- 台灣繁中、章回敘事自然；角色性格不被統一成同一種口吻。
- 家事、遊歷、軍政都能推進，不強迫所有角色成為帝王或走固定主線。
- 主角親臨戰鬥有空間與因果，技能演出忠於原檔；不靠一句「大勝」跳過。
- 天下大勢簡短但有實質變化；未發生大事不虛構危機湊字數。
- 金錢、死亡、職位與地點可由紀錄追查；前台仍易讀，不被工程面板淹沒。

- 敘事品質需另按 `docs/NARRATION_EVALUATION.md` 記錄人物聲音、繁中自然度、場景錨點與事實忠實度；mock、未帶金鑰的回退與真實模型評估分開標示。
