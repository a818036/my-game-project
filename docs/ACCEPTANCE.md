# 驗收案例

每項測試以對應原檔條文為準。自動測試判斷資料與行為；敘事品質另做人工檢查。測試應覆蓋結果，不只測函式有被呼叫。

| ID | 情境／操作 | 預期結果 |
|---|---|---|
| A01 | 相同種子及命令重跑十回合 | 狀態、事件、RNG 結果相同；不同選擇可產生不同結果 |
| A02 | 已有世界線再開新局 | 不帶入舊家產、人物、軍隊與故事；舊存檔仍可讀 |
| A03 | 測試最近三次出生地與家族姓氏 | 按原檔範圍去重；確認前清楚顯示結果，不暗中換種子 |
| A04 | 連點同一選項或重送同一命令 | 僅推進一次、只扣一次資產；過期 revision 不覆寫新狀態 |
| A05 | 儲存交易失敗及重新整理 | 不留下半套帳務／時間；恢復上一可用狀態並顯示錯誤 |
| A06 | 匯出、匯入、毀損或未知版本匯入 | 有效檔可續玩；無效檔不破壞當前世界線 |
| A07 | 第 5、10、15、20 回合 | 小結與大結節點正確，10／20 不重複小結；每回合有天下大勢 |
| A08 | 嘗試一般五維超過 100、普通核心技能超過五個 | 一般規則阻擋；天生技不因這兩限制被削弱或占用名額 |
| A09 | 新增子女／收養改名或國號 | 顯示待命名決策，不能由旁白自定正式名稱 |
| A10 | 同齡叔姪、收養、喪親等家庭案例 | 稱謂依關係圖；死亡人物仍可查，但不再出席或任職 |
| A11 | 私帳支付、公帑收入、藏界代管物資 | 每帳可追溯；保管不變成所有權；不能重複增加財產 |
| A12 | 重算一筆已知錯帳 | 從可靠紀錄重播，不用無來源的平衡金額補丁 |
| A13 | 遠方人物接收單向傳音 | 可收到，但不能憑空同場回話；回覆須另有通道及時間 |
| A14 | 同一人物回合內多次發言、換場、出入場 | 首次姓名年齡官職正確；後續不重複標籤；場景與在場名單一致 |
| A15 | 倉庫級糧貨收進藏界、主角閃至異地取出 | 數量守恆、不增負重、運輸成立；部下不能自行開藏界 |
| A16 | 箱內藏活人或屍體、遠方府庫、損壞器物入藏界 | 不可收入人類身體、不隔空偷遠貨、不自動修復；不要把禁人擴大為禁全部生命 |
| A17 | 共夢／異夢各搭配三種幻術深度 | 分發與深度獨立；入實／五感實相產生相應真實後果；非致命意圖不升級致命 |
| A18 | 純惑感導致墜落與五感實相直接致傷 | 分開事故與直接傷害來源；群體規模不自動稀釋能力 |
| A19 | 對高意志名將施高強度威壓 | 壓制成立、表現可因性格不同；恐懼與創傷保留，不自動改忠誠或人格 |
| A20 | 詛咒解除、雷電環境後果、萬解敵盾 | 不自動修復詛咒累傷；雷電依場景處理次生影響；盾被分解後不能再當完整戰利品，持盾者不直接被分解 |
| A21 | 大攻擊撞上極限收斂、一般友善接觸 | 不以護盾血量耗盡；作用範圍及選擇性接觸正確，不擴成全軍免疫 |
| A22 | 回春、治療、百脈改善與封將、推演未知情報 | 實歲不變、無自動復活；百脈效果只改受術者的已建模生理功能、封將實際限制戰鬥動作且可解除，不授予天生技；未知情報不被推演成已知真相 |
| A23 | 跨年跳過史實人物死亡窗，玩家僅持有治療能力 | 節點仍處理；持有技能或一般保健不等於成功介入 |
| A24 | 明確成功救回硬節點，再推進時間 | 同一節點標記打破，不補殺；另有新死亡原因才另算 |
| A25 | 只玩家庭回合，同時有官員亡故／外地事件 | 人事空缺、繼任、人才與天下照常運作；不等玩家問才補跑 |
| A26 | 史實事件原承載者消失／核心原因消失 | 前者只在有合理承載者時反彈；後者可取消，不機械強迫歷史重演 |
| A27 | 四項行動複選及「繼續」 | 選項點擊只更新勾選；一次送出為一份計畫且只推進一個回合；「繼續」不暗中批准尚待決策事項。互動覆寫詳見 `docs/DEVELOPMENT_OVERRIDES.md` |
| A28 | NPC 只目擊一次藏界異象 | 不知道容量、全部限制或技能後台名稱；傳聞須按渠道到達 |
| A29 | 吩咐使者談判，對方提出永久割地 | 保存草案並等待玩家批准；臨時停戰與永久主權分開；無有效授權不承諾 |
| A30 | 萬人大戰、多線部隊移動、傷亡結算 | 兵員不重算，指揮與預備隊明確，地點不分身，未知敵情標示估計 |
| A31 | 主角低調親臨戰場 | 仍詳細呈現場景與行動，局部目擊逐步傳播；不直接全軍知道主角來歷 |
| A32 | 天下統一且玩家選繼續人生 | 不自動終局；保留善後，之後適當節點可再選結局 |
| A33 | AI 輸出不存在的傷亡／錢糧或錯誤發言者 | 拒絕其狀態主張；不能改寫引擎結果，必要時回退範本 |
| A34 | AI 逾時、取消、重試同一段敘事 | 遊戲命令不重做；已提交結果保留；使用者可繼續 |
| A35 | 自由輸入被理解為不同目標或永久承諾 | 顯示解析或要求遊戲內澄清；不擅自實施含義不同的動作 |
| A36 | 檢查前端產物、請求與日誌 | 不含服務金鑰；各 NPC 敘事資訊不自動包含全世界秘密 |
| A37 | 複選耕讀與經商並送出 | 同回合各自結算一次，資產逐筆可追溯；時間、摘要與四後台引擎僅推進一次 |
| A38 | 複選超過工程負荷或互斥行動 | 送出前顯示具體衝突與受影響選項，不執行、不消耗；玩家調整後才可送出 |
| A39 | 未勾選、補充說明空白後送出 | 送出被阻止，不推進回合 |
| A40 | 有選項並輸入未解析補充說明；另測僅有文字 | 前者需明確確認僅執行勾選項目，文字保存為註記且不偽稱已解析；後者只保存註記，不耗時／資源 |
| A41 | 快速重複送出及保存失敗 | 同一提交至多結算一次；失敗時勾選及文字仍保留，可重試 |
| A42 | 手機／桌面以 18px、24px 查看選項與表單 | 選項、文字框與按鈕可鍵盤／觸控操作，焦點可見；無文字截斷、重疊或水平溢出，textarea Enter 換行 |
| A43 | 手機及桌面瀏覽東漢末年敘事主畫面 | 米白紙面、墨色文字、深木色與朱紅印記保持高對比與留白；日期、人物、地點、天下大勢套用一致樣式，正文不使用書法字體 |

## 人工遊玩檢查

- 台灣繁中、章回敘事自然；角色性格不被統一成同一種口吻。
- 家事、遊歷、軍政都能推進，不強迫所有角色成為帝王或走固定主線。
- 主角親臨戰鬥有空間與因果，技能演出忠於原檔；不靠一句「大勝」跳過。
- 天下大勢簡短但有實質變化；未發生大事不虛構危機湊字數。
- 金錢、死亡、職位與地點可由紀錄追查；前台仍易讀，不被工程面板淹沒。
- 手機窄螢幕、鍵盤操作、長文捲動、存檔失敗與等待狀態可用。

發布前另跑長局測試，涵蓋多次跨年、死亡與繼任、改朝換代、存檔遷移；記錄測試資料量、執行版本及失敗結果，不能只報告「測試通過」而不說測了什麼。
