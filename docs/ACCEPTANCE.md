## 人工遊玩檢查

- 台灣繁中、章回敘事自然；角色性格不被統一成同一種口吻。
- 家事、遊歷、軍政都能推進，不強迫所有角色成為帝王或走固定主線。
- 主角親臨戰鬥有空間與因果，技能演出忠於原檔；不靠一句「大勝」跳過。
- 天下大勢簡短但有實質變化；未發生大事不虛構危機湊字數。
- 金錢、死亡、職位與地點可由紀錄追查；前台仍易讀，不被工程面板淹沒。
- 手機窄螢幕、鍵盤操作、長文捲動、存檔失敗與等待狀態可用。
- 敘事品質需另按 `docs/NARRATION_EVALUATION.md` 記錄人物聲音、繁中自然度、場景錨點與事實忠實度；mock、未帶金鑰的回退與真實模型評估分開標示。
- 真實供應者人工案例按 `docs/PHASE5_REAL_AI_ACCEPTANCE.md` 執行；無金鑰時只可標記為待驗證，不可把 fake adapter 結果當真實模型通過。

發布前另跑長局測試，涵蓋多次跨年、死亡與繼任、改朝換代、存檔遷移；記錄測試資料量、執行版本及失敗結果，不能只報告「測試通過」而不說測了什麼。


## ChatGPT 訂閱登入補充驗收

離線測試包含官方 OAuth 參數、簽章／身份／scope 驗證、模型目錄、更新與登出、串流完成判定、跨來源拒絕及不切換付費 API。本人登入與選模成功；修補串流後真實行動解析及敘事各以一次短案例通過。新 `/api/interaction` 情境分類與敘事文風仍待重新登入後人工驗收；詳見 CHATGPT_SUBSCRIPTION.md。

### 2026-10-28 情境流程

- A52–A54 的實作輪廓：理解輸入類型 → 回答情境 → 形成待確認行動 → 玩家確認 → 規則引擎結算。
- 童年日常只改回合經驗、世界日曆、在場既有人物及自動後台，不增加成人錢財／五維／外出效果。即時對話是獨立操作；只可找明確指定的在場 NPC，且不推進時間或修改關係。每項日常可選 1、7、30 或 90 日；這是可調工程時間選項，不是規則手冊的年齡限制或成長公式。
- 長日程按日處理史實事件；遇重大節點中斷，只記完整完成的日常項目。成人四生活行動仍保留，特定目標與路線的交互尚未全數接回新面板。
- 新生活事件存政策版本及穩定選項 ID；原事件流不重寫。天生技仍通過專用 resolver 個別判斷。
- 生命階段／事件 reducer 自動案例曾在本輪程式快照執行；其後修正日曆推導年齡與成人行動紀錄 enum。最終快照型別檢查、正式建置、伺服器語法及瀏覽器質疑案例通過。尚未對最終快照重跑完整 Vitest 套件；真實 `/api/interaction` 尚待重新登入實測。

### 2026-10-28 問句與串流回歸

- 「我才幾歲!?」屬唯讀年齡詢問：本機回答存檔年齡；即使有勾選行動，也不 dispatch、不寫存檔、不呼叫 AI、不推進時間／資源。混合行動句不套用此捷徑；未實作通用聊天。
- 幼年畫面依現有開局模型顯示月齡；旁白請求補上主角年齡／月齡與現代記憶標記。現代記憶不視為身體成年，不擅加天生技年齡封鎖。
