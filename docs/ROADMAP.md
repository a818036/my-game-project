# 循序開發路線

每一階段都以可玩的成果及驗收為出口，不把整份規則一次丟給模型要求全部寫完。階段順序是工程安排，不改變最終規則。

| 階段 | 可操作成果 | 範圍與出口 |
|---|---|---|
| 1：可玩骨架 | 建立世界線、出生確認、連續十回合、四選項、天下大勢、存讀檔 | 一個地方、少量明示為測試資料的人物；確定性規則與範本敘事；四引擎介面全部存在，其中小型資料至少能展示人事、人才、歷史節點與外部事件。自訂文字先提示尚未支援完整解讀。通過 A01–A07、A11、A27 |
| 2：人生與資訊 | 家庭圖譜、成長、命名、恩怨、多帳戶、通訊與持續傷勢 | 完成一般五維／普通技能限制、在場與資訊規則；15／20 回合摘要；通過 A08–A14、A25、A28 |
| 3：完整天生技 | 能力選擇、目標／強度／排除及結算紀錄 | 逐一登錄原檔所有能力與派生式，實作各能力群，特別測試藏界＋閃、幻術兩維、威壓、萬解、防禦與治療；通過 A15–A22，沒有未實作能力卻標示成功的情況 |
| 4：歷史與軍政世界 | 歷史時間窗、招攬競爭、官職繼任、政策後效、地圖路線、戰役與主權決策 | 小型歷史內容包先驗證；死亡節點與事件反彈分開；主角親臨戰鬥完整呈現；通過 A23–A26、A29–A32 |
| 5：AI 敘事與自由行動 | 繁中敘事、mock／真實模型行動候選、在場人物即時對話切片 | 伺服器代理、資訊分層、結構與語意驗證、有限重試及範本回退；不讓模型直接改狀態；通過 A33–A36、A49–A51，真實連線與品質評估另須有金鑰實測 |
| 6：內容擴充與發布準備 | 更完整地理／史實資料、長局、手機與無障礙體驗、結局 | 資料有來源、存檔遷移、長局回歸、效能量測及人工遊玩；完成全部驗收後才稱為完整目標版本；部署另有明確目標再做 |

## 第五階段出口追蹤

情境輸入依序辨識詢問、質疑、對話、行動、混合或不明。問句只查目前狀態；嬰幼兒至少年選觀察、聆聽、溫習或休息等在地日常，不把成人生活選項套在身上；每項安排可選 1／7／30／90 日並逐日處理重大節點。成年後保留既有四種生活行動。新事件記錄穩定選項 ID 與政策版本，舊事件流不重寫。模型收到最少年齡、位置、在場人物和候選項目；schema 限制候選 ID，確認後規則引擎才結算。即時對話只支援明確指定的一位在場人物，使用該 NPC 自己已知的資訊，並在本頁保留最近四次交談以延續話題；對話不推進時間或改變關係。長期對話記憶、人物性格、多 NPC 同場互動及完整成人目標／路線仍待實作。天生技操作台獨立，個別效果遵照能力規則，不由一般年齡選項一概封鎖。

`/api/interaction` 由真實 provider 提供結構化分類和對玩家的簡短回覆；mock 以保守分類支援基本問句／行動，其他句子澄清。前端在本機明確辨識問句／質疑／混合時，拒絕模型把它升成行動。新情境流程仍需真實帳戶案例及長局文風／因果人工驗收；短案例不代表完整出口。詳見 `docs/ACCEPTANCE.md`、`docs/PHASE5_REAL_AI_ACCEPTANCE.md`、`docs/NARRATION_EVALUATION.md` 與 `docs/DEVELOPMENT_OVERRIDES.md`。

## 第一階段的實際遊玩範例

輸入姓名 → 指定種子或隨機出生 → 查看家庭與出生結果 → 確認 → 在地方生活事件中選擇學習、助家、交遊或休養等互斥主要行動 → 看見時間、關係或資源改變，以及外界消息 → 第五回合小結 → 第十回合大結 → 重新整理後續玩 → 匯出存檔並在新世界線旁匯入驗證。

此範例的具體故事與數值是測試內容，不冒充原檔已有劇本。不允許用固定十頁文字假裝回合引擎；至少有兩種選擇造成可重播且不同的狀態結果。

## 每階段交付方式

先檢查倉庫現況，沿用已完成內容。每次提交變更、執行方式、實際檢查結果與未完成清單。若使用 GitHub PR 流程，PR 只包含本階段可審查的範圍。前一階段失敗先修復，不疊加後續大型功能掩蓋問題。

不先承諾固定總工期：完整世界資料與 AI 語意驗證是主要變動來源。先完成第一階段，用實際遊玩結果確認操作手感與資料結構再估後續工作量。

## 第四階段出口追蹤

第四階段以小型歷史／軍政內容包驗證節點、人事、政策、路線運輸、戰役和重大主權決策：A23–A26、A29–A32。內容來源與日期精度記錄於 `docs/HISTORY_CONTENT.md`。未有可靠來源的地名、職缺、人才、路線、經濟與戰役數值均標示示例或可調工程參數。完整史實資料庫、完整軍政世界模擬與 AI 不屬於本階段出口。

實作狀態以對應 PR 驗證為準；本表保留原始階段目標，不以文字標記替代行為測試、型別檢查及正式建置。

#### §9.3C 戰場視線與有限因果鏈切片（未達階段出口）

戰役示例現可用正規化 2D 座標、視距與圓形遮擋物計算目標可見、超出視距或被遮擋；沒有座標的舊存檔仍使用原文字描述。另有一條受限的工程示例：直接打擊可損壞具完整度的物件，按物件位置和距離逐鏈傳力，有限次更新後件並對明確在作用半徑內的指定部隊施加士氣影響；它不增加傷亡，且不能重複結算。真實尺寸、材質、立體高差、天候、武器物理、碰撞／受力、多目標傷亡與完整傷亡軍籍結算仍未實作，因此這些切片不能宣稱 §9.3C 完成。
