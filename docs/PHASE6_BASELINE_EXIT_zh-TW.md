# 第六階段基線出口與範圍凍結

## 決定

PR #6 的可審查基線固定在歷史內容版本 **v440（A823）**。這是有限的「第六階段基線」，不是完整三國史料庫、完整地理模擬或全部人工無障礙驗收完成的宣告。

自本文件納入 PR 起，新增史實節點不再是完成這個基線出口的必要條件。後續若要擴充史料，應另立明確範圍與驗收目標；不得只因仍有史料可補，就把 PR #6 的出口無限延長。未合併的 A824 草稿不屬於 v440 基線。

## 基線包含項目

- v440 既有史料索引、來源標註與日期精度界線；未知的日期、因果、人物日常和事件效果不以推測補齊。
- 歷史內容更新的舊 v6 存檔遷移、事件帳前綴保留、不回補已過年份及重播回歸。
- 已提交的長局、結局流程、閱讀介面與自動無障礙回歸，以及 PR 自動檢查。
- A823 的完整自動驗證紀錄：255 個測試檔／1,301 項通過；型別檢查、正式建置、包體預算、正式預覽與 199 個來源網址檢查通過。GitHub Actions run [43393480302](https://github.com/a818036/my-game-project/actions/runs/43393480302) 全綠。初始 JavaScript 靜態相依為 1,053,749／1,055,000 bytes，僅是檔案大小預算，不代表裝置效能。

上列結果是 v440 基線的自動驗證證據，不表示所有史料已完整，也不替代人工驗收。

## 保留為待驗的人工項目

[人工驗收清單](PHASE6_MANUAL_ACCEPTANCE_zh-TW.md) 中 **11 條未勾選項目**原樣保留為「待驗」，不改成通過，也不因本基線出口而刪除：

1. Windows 11 搭配 NVDA／Firefox 完成主要鍵盤與讀屏流程。
2. 讀屏標題、地標、控制項、狀態播報及焦點行為檢查。
3. 焦點順序、可見性、對話框焦點限制及返回焦點檢查。
4. Windows 強制色彩與減少動態效果的實機檢查。
5. 實體 iOS／Android 手機直向、橫向操作。
6. 實體手機 200% 文字縮放操作。
7. 低階裝置效能量測及原始數據記錄。
8. 真實模型在渡口、城門、山道的敘事案例。
9. 真實模型逐項核對資訊界線、因果及敘事要求。
10. 保存去識別化真實模型輸入／輸出與判定。
11. 未參與開發的玩家獨立首次試玩。

這些工作需要實體設備、螢幕閱讀器、真實模型或未參與開發者；完成前只能如實標示待驗。人工驗收清單另列的結局流程抽查仍按原狀記錄；它們屬於後續人工驗收，不要求持續新增史料來代替。
