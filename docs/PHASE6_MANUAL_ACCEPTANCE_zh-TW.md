# 第六階段人工驗收清單

本清單只記錄自動測試、DOM 檢查與 CSS viewport 無法代替的驗收。每項都要記錄裝置／軟體版本、操作步驟、結果及日期；未實際執行時保持「待驗」，不以模擬結果代替。

## 螢幕閱讀器與鍵盤

- [x] 隔離 Chromium 鍵盤計畫操作（A308）：四個行動皆有可讀名稱；Space 勾選兩項、Enter 開啟確認區後焦點移至確認標題，返回調整後焦點回到檢視按鈕且勾選保留；未送出行動、回合未變。
- [ ] Windows 11 + NVDA + Firefox：以鍵盤完成開局姓名、出生確認、主內容跳轉、行動複選、計畫確認／返回調整、對話框開關、世界線切換、存檔失敗提示及結局提交。
- [ ] 確認標題層級與地標可導航；控制項名稱、用途、已選狀態、忙碌狀態、錯誤與成功訊息都能被讀出；舊對話不會因新回覆而整段重播。
- [ ] 確認焦點順序合理、焦點可見，沒有被遮住或困在非模態區域；關閉命名對話框與返回調整後焦點回到觸發控制項。
- [ ] 以 Windows 強制色彩模式及「減少動態效果」偏好重做上述主流程，確認選取、焦點、停用和錯誤狀態仍可辨識。

自動樣式回歸 A341 會確認系統色及減少動態效果宣告位於正確的媒體條件；它不能驗證 Windows 實際覆色、鍵盤呈現或使用者偏好是否被作業系統套用，故本項仍待人工驗收。

## 真機版面與效能

- [ ] 至少一台實體 iOS 或 Android 手機，以直向和橫向操作開局、四項全選、長註記、故事閱讀、軍政面板（含郡縣名錄搜尋）及存檔匯入；記錄機型、OS、瀏覽器、字級及是否有水平捲動／重疊。
- [ ] 在實體手機啟用 200% 文字縮放或最大系統字級，確認主要控制項仍可操作且提示不遮內容。
- [ ] 在目標低階裝置量測冷啟動、開局可互動時間、載入世界線、十回合推進及長局重播；每項至少量測五次，記錄中位數與 p95。先保存原始數據，再由專案決定正式門檻；桌機 Node 基準及 chunk 大小不能替代此項。

- [ ] 以未參與開發的玩家依 README 啟動正式預覽，記錄所需步驟、錯誤及是否能自行完成一段遊戲；這項只驗證本機使用流程，不等於公開部署。
