# 遊戲需求與規則對照

基準：規則 v3.17、天生技 v1.10。本文的 R 編號是工程追蹤編號，並非原檔條文編號。原文有細節時以原文為準。

## 1. 產品與玩家體驗

玩家在東漢至魏晉背景中經歷一生，影響人物、家族、社會與國家。主角保有設定中的 2026 年現代記憶及知識，但知識不等於已具備材料、產業或可靠情報。新世界線不可沿用其他遊戲對話中的人物、家產或故事。

預設畫面為日期、具體場景、小說敘事、簡短狀態、天下大勢、必要傳聞、四個可複選的行動項目及補充說明；明確送出後以一份計畫結算單一回合。這是 2026-10-21 玩家明確覆寫，取代原 R12 的「互斥單一主意圖」介面要求，原始手冊不修改。帳簿、人物圖譜、軍政資料與完整面板收合，玩家要求或重要變化才展開。玩家不必每回合閱讀行政報表。

## 3. 天生技需求

全部天生技須建立可讀能力目錄及可執行規則，不可只在設定頁展示名稱。下表是能力群摘要；完整名稱、派生式、適用條件與演出仍讀原檔對應章節。

| 能力群 | 必須保留的規則 | 原檔定位 |
|---|---|---|
| 軒轅之命 | 主角超自然設定基礎，與普通五維／普通技能名額分離 | §1 |
| 照膽、山河薪火、薪火不滅、群星入懷、萬民歸心 | 情緒／忠誠洞察不等於讀取全部事實；凝聚與重建依既有人心和資源，不造人、不強制投降 | §2 |
| 萬象推演、萬軍如臂 | 根據已知情報推演與統御，不能把錯誤情報直接變正確，不能讓士兵免飢餓或命令零延遲 | §3 |
| 五感天幕 | 「單體／萬軍共夢／千軍異夢」是分發模式；「惑感／入實／五感實相」是獨立深度，可交叉組合 | §4 |
| 幻術傷害 | 惑感本身不直接製造身體傷害，但可導致踩踏等事故；入實有真實生理與組織後果；五感實相有相符的真實創傷，可依意圖致命 | §4 |
| 五感盡失 | 封鎖輸入，不能與假資訊混為一談 | §4 |
| 神識威壓 | 存在層級壓制，非重力或幻術；強度、對象、排除可選；高強度可留持續創傷；恐懼不改寫忠誠人格 | §5 |
| 妖術伏地／萬軍伏地 | 持續詛咒，不是重力；解除施術不等於消除已累積傷害；群體不稀釋個體效果 | §6 |
| 雷電系 | 真實電擊與導電、聲光、碎屑、馬匹反應等次生後果照指定使用方式處理；原文示意距離不硬改成通用半徑 | §7 |
| 百脈敕令 | 按指定領域形成受術者能力改善；不是每次賜予都新增主角技能，也不讓受術者免老免傷 | §8 |
| 萬疫敕令、軒轅觀世、天醫敕生、歲月回春 | 防治、診斷、修復與生理回春分開；不自動復活；生理年齡與實歲分開，尊重受術者自主性 | §9 |
| 軒轅傳音、天下共視 | 傳音預設主角單向傳達；共視是真實即時畫面，虛構畫面歸幻術；不可自動讓遠方人物當場回答 | §10 |
| 軒轅閃 | 主角親自移動，可帶符合近旁、納入、接觸／完整整體條件的人與物；不是遙控物流或自動軍團傳送 | §11 |
| 軒轅藏界 | 非實體袋、容量與負重無限；人類活體及屍體不能收入，包箱不得繞過；不得擴大為所有生命都禁止 | §11A |
| 藏界存取 | 現場持有／接觸／近旁明確鎖定；不默認跨州偷取；取出位置須成立，不默認重疊人體攻擊；不自帶保鮮、修復、複製 | §11A |
| 藏界＋閃 | 主角甲地收貨、本人閃至乙地、取貨必須成立；國家日常物流仍需制度，兩者不矛盾 | §11A |
| 軒轅萬語 | 語言理解不等於讀心或全知文化 | §12 |
| 霸者橫攔及派生、霸骨天成 | 超自然力量與承載基礎，不能被普通武力上限削弱，也不能自動擴張為所有傷害免疫 | §13 |
| 軒轅極限收斂 | 約兩公尺個人概念防禦，選擇性接觸，保護所涵蓋衣物；不是可耗盡護盾或全軍結界 | §14 |
| 萬解 | 可選擇分解指定物品，不限有機／無機材料；不直接分解人體或動物，支撐消失等二次結果另算 | §14A |

共同規則：不擅加魔力、冷卻、次數、反噬、群體稀釋或名將免疫。手勢是演出，不是必要施法條件；發動瞬間瞳光照原文，觀察者是否看見依位置與注意力。技能後果、目擊、傳聞與政治反應分開處理。

主角性格以原檔「陳夏性格核心」及玩家最新選擇為準：重自主、有長期考量、能記恩仇、重自己人、可務實退讓但不是自動原諒。不要額外引入參考作品的修煉體系、人物或劇情，也不要用性格預設代替玩家的重大決定。

## 4. 規則交會處的實作決議

| 問題 | 本規格處理 |
|---|---|
| 普通人體限制與超自然能力衝突 | 已明載能力在其作用範圍優先；未涵蓋的普通人物、制度照常運作 |
| 天生技前言引用較早規則基準 | 依使用者最新指定採 v3.17＋v1.10；舊版引用不使整體降版 |
| 部分總則列舉引擎較少 | 綜合回合與自動後台章節，四引擎全部執行 |
| 征服與主權承諾 | 實際佔領、法律承認、談判草案、正式批准各自記錄 |
| 發令談判／繼續遊戲 | 不推定同意永久割地；需顯示具體條款與適用授權 |
| 歷史日期不明 | 資料存年／月／日精度及來源，使用明載時間窗；不捏造精確史實 |
| 免費文字與引擎命令不匹配 | 先呈現系統理解的行動；會改變重大意思時要求遊戲內澄清，不默認替換 |
| 未規定數值公式 | 以可設定的工程參數與明確標籤試作，不宣稱為原作者規則 |
| 新技能／玩家覆寫 | 建立有時間、適用範圍、來源與版本的覆寫事件；不暗改歷史存檔 |

## 5. 仍需資料建置的內容

完整史實人物、出生死亡時間窗、官制沿革、地名道路、事件核心因果、物價產出、戰鬥參數與大量地方故事，並未因有兩份規則就自動齊備。先用一小組明確標示的測試資料驗證，再加入有來源的歷史資料；未收錄者不可宣稱已完整模擬。音樂、美術、多人連線、行動商店版本、付費系統均不列為首版必需。
